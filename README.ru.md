# minga-humanize-text

Скилл для Claude Code, который убирает «ИИ-привкус» из готового текста — описаний, тегов, рилсов, песен, таблиц и отчётов, текстов для озвучки — перед публикацией или записью голоса.

Это финальная полировка: её запускают *после* того, как само содержание (факты, структура, смысл) уже готово. Писать текст за вас она не будет.

[English version →](README.md)

## Что ловит

Диагностика в два прохода по пяти группам признаков:

- **Содержание** — несуществующие источники («по данным исследований» без самого исследования), размытые обобщения, пустые похвалы, раздутая значимость, вялое «с одной стороны / с другой стороны» без собственной позиции
- **ИИ-лексика** — вводные-пустышки («в современном мире», «стоит отметить»), напыщенные слова («экосистема», «раскрыть потенциал», «бесшовный»), лишние усилители, конструкции «это не просто X, это Y»
- **Стиль** — слишком ровные по длине абзацы, примеры строго тройками там, где естественнее два или четыре, избыток тире, декоративные эмодзи, подозрительно гладкий ритм
- **Структура** — зачины «в этой статье мы рассмотрим…», концовки «таким образом, можно сделать вывод», заголовки, которые просто повторяют запрос
- **Общение** — угодливые концовки («обращайтесь, если будут вопросы»), оговорки-перестраховки, извинения перед прямой критикой

Если в абзаце два признака и больше, он переписывается целиком, а не латается построчно.

Для подписей к рилсам и постам, тегов, текстов песен, таблиц и управленческих отчётов, а также текстов для устной речи и озвучки есть отдельные заметки: у каждого формата своё «звучит по-человечески».

Если у пользователя уже сохранён профиль его стиля письма, скилл опирается прежде всего на него; если нет — на общие принципы выше.

## Установка

Скопируйте `SKILL.md` в папку скиллов:

```bash
mkdir -p ~/.claude/skills/minga-humanize-text
curl -fsSL https://raw.githubusercontent.com/dmminga1983/minga-humanize-text/main/SKILL.md -o ~/.claude/skills/minga-humanize-text/SKILL.md
```

(Или скачайте репозиторий и сами положите `SKILL.md` в `~/.claude/skills/minga-humanize-text/`.) Claude Code подхватит его в следующей сессии — без перезапуска, настроек и включения.
